Chronological Competition Lifecycle

Eight-Stage Engineering Journey

From initial problem discovery to unexpected operational disruptions, participants navigate real-world engineering chaos.

STAGE 01 Enroll
🔍

Discovery & Registration

Explore challenges, inspect eligibility, verify remaining slots (max 100), and join with institutional credentials.

STAGE 02 V1.0
📋

Problem Statement Release

Organizers publish Version 1.0 specifications and constraints. Becomes permanently immutable once published.

STAGE 03 Pathway
⚖️

Pathway Selection

Choose Pathway A (AI-Assisted) or Pathway B (Without AI). Evaluated under identical standardized rubric.

STAGE 04 Initial
🚀

Initial Solution Submission

Submit repository, architecture and declarations. Receive cryptographic receipt (NEX-SUB-YYYYMMDD-XXXXXXXX).

STAGE 05 Shift
⚡

Unexpected Problem Shift

Organizers drop Version 2.0: sensor failures, power outages, and resource restrictions. V1 remains immutable.

STAGE 06 Live Alert
🔔

Real-Time Disruption Notification

Instant real-time broadcast with side-by-side V1 vs V2 diff highlighting new operational bottlenecks.

STAGE 07 Revision
🔄

Adaptive Solution Revision

Adapt existing architecture to new constraints. Submit revision receipt (NEX-REV-YYYYMMDD-XXXXXXXX).

STAGE 08 Results
🏆

Evaluation & Results

Seven weighted criteria with Adaptability tie-breaker. Leaderboards remain hidden until official publication.

Pathway Integrity

Two Pathways. Equal Honor.

Both pathways are evaluated on identical seven-criteria standards. Neither pathway is favored.

PATHWAY A 🤖

AI-Assisted Problem Solving

Leverage modern LLMs and AI code engines while demonstrating rigorous verification, prompt engineering, and human-in-the-loop oversight.

  • ✓ Disclose AI tools and prompts submitted
  • ✓ Detail human modifications and prompt refinement
  • ✓ Provide strict verification & test coverage
  • ✓ Evaluated under Pathway Integrity (10%)
PATHWAY B 🧠

Without AI (Pure Engineering)

Tackle problems using first-principles logic, mathematical modeling, native algorithms, and independent algorithmic thinking.

  • ✓ Pure algorithmic reasoning & data structures
  • ✓ In-depth mathematical and engineering proofs
  • ✓ Native test benches and boundary conditions
  • ✓ Evaluated under Pathway Integrity (10%)
Standardized Scoring System

Seven-Criteria Weighted Rubric

A mathematically normalized 100% evaluation matrix with an Adaptability tie-breaker.

1. Problem Understanding
Root cause identification, real-world context mastery
15% Weight
2. Technical Depth
Engineering architecture, algorithm complexity & logic
15% Weight
3. Adaptability to Problem Shift (CRITICAL)
Response to Version 2.0 disruption; primary tie-breaker
20% Weight (Tie-Breaker)
4. Code Completeness
Executable quality, error handling, repository structure
15% Weight
5. Practical Feasibility
Deployability, cost considerations, hardware constraints
15% Weight
6. Pathway Integrity
Transparency in AI declarations or pure engineering logic
10% Weight
7. Innovation
Novelty of approach, out-of-the-box resilience mechanism
10% Weight
Total Composite Score 100% Complete
